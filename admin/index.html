Importar dados de resultados.fpf.pt

Cole o JSON gerado pelo scraper, ou carregue o ficheiro fpf-data.json

⚠️ O URL deve estar acessível pelo browser (sem CORS). Use o scraper para gerar o JSON e sirva-o localmente.

Como usar o scraper:
  1. Na pasta scraper/ execute: npm install
  2. Descubra o ID da AF Algarve: node fpf-scraper.js --descobrir-af
  3. Liste as competições: node fpf-scraper.js --listar
  4. Importe: node fpf-scraper.js --competicao ID
  5. Cole o conteúdo de fpf-data.json acima e clique em Importar

🔗 Obter Token
Como obter o Page Access Token:
  1. Aceda a developers.facebook.com e crie uma App
  2. Em Graph API Explorer, seleccione a sua App e a Página
  3. Adicione as permissões: pages_read_engagement, pages_read_user_content
  4. Clique em Generate Access Token e copie o token
  5. Para token permanente, converta-o com a Long-lived Token API
