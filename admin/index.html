Não configurado
🔗 Obter Token
Como obter o Page Access Token:
  1. Aceda a developers.facebook.com e crie uma App
  2. Em Graph API Explorer, seleccione a sua App e a Página
  3. Adicione as permissões: pages_read_engagement, pages_read_user_content
  4. Clique em Generate Access Token e copie o token
  5. Para token permanente, converta-o com a Long-lived Token API
