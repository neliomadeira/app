Auditar as notícias existentes

Verifica que HTML existe nas notícias já escritas, antes de se decidir o que fazer.

Esta página só lê. Não altera, não apaga e não publica nada. Não escreve uma única letra no armazenamento do painel. Pode fechá-la a qualquer momento sem consequências.

Como usar

  1. Abra esta página no mesmo endereço onde abre o painel. Se o painel está em http://127.0.0.1:5500/admin/, então esta página é http://127.0.0.1:5500/tools/auditar-noticias.html.
  2. Carregue em Analisar.
  3. Leia o resultado. Se quiser que eu faça a análise exata, use Descarregar só as notícias e envie-me esse ficheiro — leva apenas as notícias, sem inscrições nem mensagens.

O endereço tem de ser o mesmo porque o browser guarda os dados de cada endereço em separado. Aberta como ficheiro solto (file://), esta página não encontra nada.
